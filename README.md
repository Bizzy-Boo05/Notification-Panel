#  📱 Mobile-First Notification Site

A simple yet elegant notification web app built using HTML, Bootstrap, and JavaScript, designed with a mobile-first approach.
It allows notifications or updates to be displayed in a minimal UI and remain persistent until manually changed — making it ideal for announcements, alerts, or pinned messages.







# 🌟 Features

✅ Mobile-First Design – Optimized primarily for mobile devices, responsive across all screens.
✅ Bootstrap UI – Clean, modern, and consistent interface using Bootstrap components.
✅ Persistent Notifications – Notifications stay visible until someone updates them manually.
✅ Lightweight & Fast – No frameworks or heavy dependencies — just HTML, CSS (Bootstrap), and vanilla JS.
✅ Customizable – You can easily modify colors, fonts, or add new notification types.




# 🛠️ Tech Stack



Technology	                        -                                 Purpose

 
HTML5	                            -                                 Structure of the page


Bootstrap 5	                        -                                 Styling and responsive layout


JavaScript (Vanilla JS)	            -                                 Logic for persistent notifications




# 💻 How It Works


The notification content is displayed inside a card or alert box.



The message remains on screen even after reloading, until manually changed in the code or local storage.



You can edit the notification text or add more alerts easily from the HTML/JS files.
